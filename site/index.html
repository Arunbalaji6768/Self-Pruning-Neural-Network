Self-Pruning Neural Network

A CIFAR-10 classifier that learns to prune its own weights during training, using a learnable gate on every weight and an L1 sparsity penalty.

Code on GitHub · Full report

How it works

gates          = sigmoid(gate_scores)      # each in (0, 1)
pruned_weights = weight * gates            # gate near 0 = weight removed
loss           = CrossEntropy + lambda * sum(gates)

A higher lambda pushes more gates to zero. The network trades accuracy for fewer connections. A weight counts as pruned when its gate is below 0.01.

Honest notes

Numbers come from experiment_results.json, which logs 5 epochs per run. Accuracy is modest (59% at best) because the focus is the accuracy and sparsity trade-off, not a state-of-the-art score.

Pruned weights are masked to near zero, not physically removed, so this does not yet give faster inference or lower memory. Real sparse inference is the next step.
